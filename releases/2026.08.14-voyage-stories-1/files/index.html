About

Scope per Section 10.2 of the SAILVu report: map, click-to-plan route, per-leg speed, plotted ETA, gate/pass current warnings, and a current + wind-leeway ETA correction (wind added 2026-08-05 — see the Leeway % field under Layout Route). Current/wind data (SalishSeaCast/CIOPS/HRDPS) is a static pre-downloaded snapshot, not live, and the correction is a nearest-neighbor approximation — see each leg's own note. Vessel position can be set manually, read from this device, or received from Signal K.

Data refresh: Cellular Minimum updates EC forecasts and warnings while retaining model files. Voyage Region downloads the box you draw on the map. Shore Wi-Fi downloads the complete model region. A failed large download falls back to EC/tides, then EC only, without deleting the previous model files. At overview zoom 7 the map stays inside the blue Voyage Region box; zoom in farther to pan the complete map freely.

Shift+click anywhere on the map to add a route waypoint. A plain click instead queries the nearest current and wind readings at that point. Gate and tide station markers show their name and latest data on hover, and open a data/graph popup on click. Backspace removes the last route waypoint. Graph windows resize by dragging a corner. Stations are map-only, not listed in the sidebar.

Map arrow colors: blue = ambient current field (Section 8.5), green = your vessel's resultant over-the-ground track per leg (current + wind-leeway, see Leeway % under Layout Route), purple = tide (high/low water level) stations, gold = wind (10m, HRDPS forecast — off by default; enable under Wind/Weather → Modelled winds). The gold arrows themselves are just a map visualization — the underlying wind data they're drawn from is the same data the leeway calculation reads, whether or not this layer is switched on. Blue, green, and gold arrows all point in the direction that quantity is moving toward. Blue and green arrows share the same length scale (length = distance that speed would cover in one hour) so a 1-knot current and a 1-knot vessel speed always look the same length — compare them against the bottom-left scale-arrow legend. Gold wind arrows use a fixed shaft length instead, regardless of speed (not comparable to the scale-arrow legend); speed is shown by feather-style marks near the tail instead (a triangular pennant = 50kn, a long feather = 10kn, a short feather = 5kn, rounded to the nearest 5kn).

Gate station markers and gate warnings also show a SalishSeaCast model sample at that station — a separate data source shown alongside the CHS harmonic prediction, not a formal comparison (Section 6.7 remains closed). Tide predictions are CHS high/low events at four stations around the region — a separate set of stations from the current gates, not corrected for at all in route ETAs. Offline CANVEC and downloaded forecasts work without internet; online base maps and fresh data downloads require a connection.

The floating control at the bottom of the map scrubs current/wind/ wave layers and gate/tide/wind station tooltips through whatever snapshots are already on file — drag its slider, use PgUp/PgDn, or press either Auto button for playback. Press Auto again or NOW to stop; PageUp/PageDown/Home work from the keyboard (Home returns to live). It does NOT affect route ETA or ground-track correction, which always use real elapsed time for each leg regardless of what the map is currently showing.

Sea State

The signed interaction index is the component of current flowing in the wind direction: current speed × cos(angle between wind and current).

Negative values mean opposing wind and current, where waves may become shorter, steeper, choppier, and more confused. Positive values mean wind and current travel together; values near zero mean cross-flow or weak current.

This combines the selected SeaCast or CIOPS current source with the nearest 10 m HRDPS wind model sample at the displayed map time. It is a planning indicator, not a direct wave-height or sea-state forecast. Local bathymetry, shoreline effects, swell, and model resolution can materially change actual conditions.
